# اپلیکیشن کتابخانه (BookApp)

## ساختار جریان اپلیکیشن
ورود (Login) → فهرست دسته‌بندی‌ها → فهرست زمینه‌ها → فهرست کتاب‌ها → فهرست فصل‌ها → فهرست بخش‌ها → متن کامل بخش

## چگونه پروژه را باز کنم؟
1. **Android Studio** (نسخه Iguana یا جدیدتر) را نصب کنید.
2. پوشه `BookApp` را با گزینه **Open** در Android Studio باز کنید.
3. صبر کنید Gradle Sync تمام شود (نیاز به اینترنت برای دانلود کتابخانه‌ها دارد).
4. روی دکمه **Run ▶** بزنید تا روی گوشی یا شبیه‌ساز نصب شود.

با اولین اجرا، برنامه به‌طور خودکار داده‌های نمونه از فایل
`app/src/main/assets/sample_data.json` را در دیتابیس داخلی (Room/SQLite) وارد می‌کند.

## چطور محتوای واقعی (فایل ورد) را اضافه کنم؟

### روش پیشنهادی: تبدیل Word → JSON
1. فایل ورد خود را طبق قرارداد زیر با **استایل‌های Heading** بنویسید (در Word از پنل Styles استفاده کنید):
   - `Heading 1` = عنوان دسته‌بندی
   - `Heading 2` = عنوان زمینه
   - `Heading 3` = عنوان کتاب (خط بعدش می‌تونه `نویسنده: ...` باشه)
   - `Heading 4` = عنوان فصل
   - `Heading 5` = عنوان بخش
   - پاراگراف‌های معمولی زیر Heading 5 = متن همان بخش

2. اسکریپت پایتون را اجرا کنید:
   ```bash
   pip install python-docx --break-system-packages
   python scripts/docx_to_json.py my_book.docx output.json
   ```

3. فایل `output.json` تولیدشده را جایگزین
   `app/src/main/assets/sample_data.json` کنید.

4. چون داده فقط وقتی دیتابیس **خالی** باشد وارد می‌شود، برای دیدن داده جدید
   باید اپ را پاک‌نصب کنید یا داده اپ را از تنظیمات گوشی پاک کنید (Clear Data).

### اگر چند کتاب/فایل ورد دارید
اسکریپت را برای هر فایل جدا اجرا کنید و خروجی‌های JSON را در یک آرایه واحد
ادغام کنید (یا اسکریپت را برای پردازش چند فایل با هم توسعه دهید).

## نکته درباره صفحه ورود (Login)
در نسخه فعلی، صفحه ورود فقط بررسی می‌کند که فیلدها خالی نباشند (بدون اتصال
به سرور). اگر نیاز به احراز هویت واقعی (مثلاً با نام کاربری/رمز از پیش
تعریف‌شده یا اتصال به یک API) دارید، بگویید تا آن بخش را هم اضافه کنم.

## ساختار پوشه‌ها
```
BookApp/
├── app/src/main/java/com/example/bookapp/
│   ├── MainActivity.kt
│   ├── data/            # Entity ها، DAO ها، دیتابیس Room
│   └── ui/
│       ├── AppNavigation.kt   # مسیریابی بین صفحات
│       └── screens/           # صفحات Login، فهرست عمومی، متن
├── app/src/main/assets/sample_data.json   # داده‌های کتابخانه
└── scripts/docx_to_json.py                # تبدیل Word به JSON
```
